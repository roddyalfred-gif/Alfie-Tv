# Alfie TV Roadmap

## Phase 1: Core Infrastructure ✅ (Current)

- [x] Monorepo setup with npm workspaces
- [x] Core streaming engine (HLS/DASH)
- [x] Channel management system
- [x] EPG (Electronic Program Guide)
- [x] User management
- [x] Customizable splash screens
- [x] Theme system (dark/light)
- [x] Web application (React)
- [x] Backend API (Express)
- [x] 4K support
- [x] TypeScript configuration

## Phase 2: Enhancement & Features (Next)

- [ ] M3U playlist support
- [ ] XMLTV EPG integration
- [ ] Advanced search and filtering
- [ ] Watch history
- [ ] Recommendations engine
- [ ] User authentication (JWT)
- [ ] Database integration (MongoDB)
- [ ] Caching layer (Redis)
- [ ] Performance optimization
- [ ] Testing suite (Jest, Vitest)

## Phase 3: Cross-Platform (Future)

- [ ] React Native mobile app (iOS/Android)
- [ ] Electron desktop app (Windows/macOS/Linux)
- [ ] React TV smart TV app (Android TV/webOS/Tizen)
- [ ] Progressive Web App (PWA)
- [ ] Offline support
